Program tree — fully collapsed subtree

A composite node can be collapsed. Its whole subtree leaves the canvas and is listed inside the node instead; a nested composite is a box that encloses its own children, like Groot's nested collapsed view (the partial, direct-children view is not proposed). Every listed node keeps showing its live execution status. Press Play run and collapse pick or place while it runs.

Proposed rules

  • Only composites collapse (nodes with children). The chevron sits in the node's empty right band, so the node keeps its size and layout when expanded. It is quiet (no border, faint background) and brightens when the node is hovered. Right-click adds Collapse subtree / Expand subtree; the canvas toolbar adds Collapse all / Expand all.
  • Collapsed means fully collapsed: every descendant is listed, at any depth; a nested composite is a box around its own children. Collapsing a node inside an already collapsed one has nothing to show until expanded; expanding restores descendants' own collapsed state. Collapse all collapses every composite including the roots, so the whole Program becomes one box per root; expanding a root then shows its children still collapsed.
  • Width: expanded nodes keep the fixed node width. A collapsed node grows to fit its deepest and longest row, from the node width up to a cap (340 px here); past the cap, names end in "…" with the full name in the tooltip. Later columns move right by the extra width.
  • Status stays live: the collapsed node's border is its own status, as today; each row shows its node's status (running rows glow). A failure deep inside a collapsed subtree is visible without expanding.
  • Right-click: on a node, the menu starts with Collapse (or Expand on a collapsed node; disabled on a leaf), Collapse all and Expand all, then the existing node commands. On a row inside a collapsed node, the first entry is Show on canvas, which expands its collapsed ancestors. On empty canvas: the existing Paste here, Add node here, Auto-layout, Fit view, then Collapse all and Expand all. On an edge: Disconnect, which detaches the child subtree as a separate root (the same operation as double-clicking the edge today). A node's own chevron opens that node's menu; over toolbar and panel buttons no canvas menu opens. In this mock, the existing commands only show a notice.
  • Rows are the nodes: clicking a row selects that node and opens it in the Program inspector; an invalid or unavailable row shows the same kind symbol as the node would.
  • View only: collapsing never edits the Program. Auto-layout treats a collapsed node as one tall node. Editing links into a hidden node needs it expanded (drops onto a collapsed node append as the last child, as now).
  • Open choice: keep the collapsed set per browser (like edge style), or save it with the Program's viewer metadata so it follows the file.
